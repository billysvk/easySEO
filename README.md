# easySEO

Advanced Python CLI tool designed to automate deep YouTube video optimization using the official Gemini SDK.

## Features
- **Image Processing**: Extract data and retention info from YouTube Studio screenshots.
- **SRT Parser**: Parse subtitles and clean transcription speech text.
- **URL Analysis**: Fetch and parse web contents and metadata.
- **Info Reader**: Ingest titles and descriptions.
- **Proposal Generation**: Orchestrates a final SEO proposal utilizing Google Gemini models.

## Quick Start

### Installation
Ensure you have `uv` installed, then run:
```bash
uv sync
```

### Run CLI
```bash
uv run python -m src.cli --help
```
